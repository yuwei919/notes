 ```
#include<stdio.h>
 
int main()
{
	printf("To C, or not to C;that is the question\n");
	return 0;
 } 
 ```
转换的3个步骤
 * **预处理**。首先程序会被交给预处理器。预处理器执行以#开头的命令（通常称为指令）。
 * **编译**。修改后的程序现在可以进入编译器了。编译器会把程序翻译成机器指令（即目标代码）。
* **链接**。链接器把由编译器产生的目标代码和所需的其他附加代码整合在一起，这样才最终产生了完全可执行的程序。
C程序的一般形式：
```
指令
int main()
{
	语句
}
```
C程序的三个语言特性：**指令**，**函数**和**语句**。
##### 指令
**预处理器执行的命令称为指令。**
程序中\#include是指令，作用是吧<xx.h> 的信息包含在程序
。
所有指令都以字符\#开始
##### 函数
函数是用来构建程序的构建块。
函数分为两大类：一类是程序员编写的函数，另一类则是C语言提供的函数。后者为**库函数**1。
计算数值的函数用return指定返回的值
```
#include<stdio.h>
 
int main()
{
	printf("To C, or not to C;that is the question\n");
	return 0;
 } 
```
main前的**int**表明函数将返回一个整数值，（）代表main函数没有参数。
```return 0;```有两个作用：一是使main函数中止，二是指出main函数的返回值是0。
##### 语句
语句是程序运行时执行的命令。上文程序只用到两种语句：一种是**返回**语句，另一种是**函数调用**语句。
C语言规定每条语句都要以分号结尾，但指令不需要。
##### 显示字符串
printf函数用于显示**字符串**，显示结束时printf函数不会自动跳转到下一行，显示的字符串中必须包含\n来完成换行。
换行可以在一个字面串中多次出现。如显示下图信息
```
Brevity is the soul of wit.
--Shakespeare
```
可以这样写：
```
	printf("Brevity is the soul of wit.\n --Shakespeare\n");
```
### 注释

一般用/* \*/实现多行注释
```
/*
需要注释的内容
可以多行
*/
```
用//实现单行注释
```
//需要注释的内容，只能注释一行
```
### 变量和赋值
C语言将临时储存数据的存储单元称为**变量**。
##### 类型
每一个变量都必须有一个**类型**。类型用来说明变量所存储的数据的种类。
我们暂时只用两种：**int类型**和**float类型**。
int型变量看存储整数，最大值通常是2 147 483  647，部分计算机上可能是32 767。
float型变量可以存储比int型变量大得多的数值，且可以带小数。但float储存的是近似值，且运算速度比int慢。
##### 声明
使用变量前必须对其进行**声明**。声明变量的一般方式为：
```
	int height;
	float profit;
```
如果几个变量类型相同，我们可以合并：
```
int height,length,width,volume;
float profit,loss;
```
每一条完整的声明都必须以分号结尾。
当main函数包含声明时，必须把声明放置在语句之前。
```
int main()
{
	声明
	语句
}
```
###### 赋值
变量通过赋值的方式获得值：
```
height = 8;
length = 12;
width = 10;
```
变量在赋值或以其它方式使用前必须声明：
```
int height;
height = 8;
```
我们在把一个包含小数点的常量赋值给float时，常常在后面加上f;
```
profit = 2150.48f;
```
变量被赋值后，可以辅助计算其他变量的值：
```
height = 8;
length = 12;
width = 10;
volume = height*length*width;
```
赋值右侧含有常量、变量和运算符的公式称为**表达式**。
##### 显示变量的值
用printf可以显示变量的当前值，如：
```
printf("Height:&d\n",height);
```
显示为：
```Height:8```
其中&d用于表示int型变量，%f表示float型变量。
float型变量一般默认显示6位小数，若要显示p位，可以写为
```
printf("&f.2\n",height);
```
同时printf可以显示多个变量，如：
```
printf("Height:&d,Length:&d\n",height,length);
```
##### 初始化
没有默认值且未被赋值是**未初始化的**。
```
int height = 8;
```
数值8是一个**初始化器**。
##### 显示表达式的值
printf可以显示任意数值表达式的值：
```
printf("%d\n",height*length*width);
```
### 读入输入
scanf用来获取输入，scanf和printf中的f都表示格式化，它们都需要用**格式串**来指定输入数据或输出数据的形式。
### 定义常量的名字
**宏定义**给常量命名：
```
#define INCHES_PER_POUND 166
```
\#define是预处理指令，因此结尾没有分号。
